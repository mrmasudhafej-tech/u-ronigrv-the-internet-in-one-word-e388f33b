One word for the whole internet: **Unhinged**.

The internet does not behave. In a single scroll it swings from a
heartwarming rescue video to a shouting match, a wild rumour, a
brilliant idea and a joke nobody asked for, with no warning and no
apology. "Unhinged" catches that swing in one beat: it is funny the
moment you read it, it is true of the internet everywhere rather than
of one app or one trend, and it is a sharper, more surprising choice
than a plain word like "chaos". It makes you laugh first, then nod,
because you have seen exactly that behaviour today.

Running the program writes that one word, and nothing else, to
`entry.txt`: exactly the eight letters `Unhinged`, with no trailing
newline and no extra whitespace.

## Run it

```sh
python3 main.py
```

The program uses only the Python standard library. It writes to the
folder named by `MAKEFUN_OUTPUT_DIR` when that variable is set, and to
`/output` otherwise.
